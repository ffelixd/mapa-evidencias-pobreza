# Mapa de evidências e lacunas: pobreza no Brasil

Página interativa que acompanha a síntese rápida de evidências sobre determinantes, persistência e efeitos da pobreza no Brasil (FGV CLEAR para o MDS). Versão de trabalho.

## Como abrir

A página é um único arquivo, `index.html`. Não precisa de instalação nem de servidor.

- No computador: baixe o arquivo e abra no navegador.
- Pelo GitHub Pages, se estiver ativado: use o endereço que aparece em Settings > Pages.

## O que há na página

| Aba | O que mostra |
|---|---|
| Achados | Os 16 destaques do resumo, os 109 achados dos Quadros 4 a 18 por nível de confiança e as lacunas |
| Mapa | Temas do quadro analítico por região, urbano e rural e extrema pobreza, com os estudos de cada célula |
| Árvore de problemas | Determinantes, problema central e efeitos |
| Base de estudos | Os 359 estudos, com citações, achados extraídos e os achados do relatório que cada um sustenta |
| Como ler e como foi feito | Convenções de leitura e método |

## Árvore de problemas

A pasta `arvore/` traz a árvore de problemas atualizada, com o pôster A1 e a página interativa de cada achado. Com o GitHub Pages ativo: https://ffelixd.github.io/mapa-evidencias-pobreza/arvore/

## Fontes dos dados

- Relatório: `Sintese_Pobreza_Achados.docx`.
- Planilha: `Sintese_Pobreza_Base_de_Evidencias.xlsx`, versão de 01/10/2026.

Os dados estão embutidos no `index.html`. Para atualizar a página, substitua o arquivo por uma nova versão.
